# velmourche

Личная страница: [velmourcnikita.github.io](https://velmourcnikita.github.io/).

Статический HTML, CSS и JavaScript без сборки. Изменения в main публикуются через GitHub Pages.

- Статус Discord из Lanyard; недоступность сервиса отображается отдельно от офлайна.
- Фоновая музыка через официальный SoundCloud Widget API после первого нажатия. Пауза, громкость и сохранение выбора в браузере.
- Снег ограничен 24 кадрами в секунду и останавливается в скрытой вкладке. Эффекты отключаются кнопкой и учитывают системное уменьшение движения.
- На компьютере курсор получает плавный хвост, а подсветка карточек следует за мышью. На сенсорных устройствах и при отключённых эффектах остаётся обычный указатель. Координаты обрабатываются только для отрисовки в браузере.
- При недоступности SoundCloud остаётся прямая ссылка на трек.

Для локального просмотра запусти статический HTTP-сервер из этой папки.
